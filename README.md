# UI Traps

A polished field guide to UX anti-patterns, corporate process, and confidently incorrect AI. The site presents nine organizational design traps through a colorful card gallery, satirical research findings, and interactive demos.

## Features

- Responsive editorial home page and trap gallery
- Dedicated detail view for each of the nine traps
- Distinct interactive demo for every anti-pattern
- Accessible controls and reduced-motion support
- React, TypeScript, Vite, and Lucide icons

## Development

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Validation

```bash
npm run build
npm run lint
```
